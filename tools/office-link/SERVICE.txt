HR HUB Link — Windows Service (Faza 2)
======================================

Maqsad
------
GUI («Ulash») yopilganda ham device-gw (8800) + Cloudflare tunnel ishlab tursin.
Punch / face sync platformadan ofis LAN qurilmasiga yetib borsin.

Auto-heal
---------
• GUI: «Internet tunnel» kartasi — holat, «Tunnelni tiklash», avtomatik tiklash
• service_worker.py: jarayon yoki tunnel URL o‘lik bo‘lsa qayta ochadi + announce
• Oyna yopilganda tunnel o‘chirilmaydi; fon ishchi (yoki Service) davom etadi
• Quick trycloudflare URL har restartda yangilanadi — announce majburiy

Tayyorgarlik
------------
1. Web → Устройства → Связь с офисом — pairing token
2. HRHUB-Qurilma.exe — token, lokatsiya, «Ulash» (muvaffaqiyatli)
3. data\service.json avtomatik yoziladi; data\link.key bo‘lishi kerak

O‘rnatish
---------
1. O‘ng tugma → install-service.bat → «Запуск от имени администратора»
2. NSSM (tavsiya): nssm.exe ni shu papkaga qo‘ying (https://nssm.cc)
3. Service nomi: HRHUB-OfficeLink
4. Holat: data\service_status.json
5. Tunnel URL: data\tunnel_url.txt

Muqobil: Task Scheduler
-----------------------
1. taskschd.msc
2. Create Basic Task → HRHUB-OfficeLink
3. Trigger: At startup (yoki At log on)
4. Action: Start a program
   Program: pythonw.exe (yoki runtime\python\pythonw.exe)
   Arguments: "C:\...\HRHUB-Link\service_worker.py"
   Start in: C:\...\HRHUB-Link
5. Run with highest privileges

Named tunnel (barqaror URL)
---------------------------
config.json:
  "cloudflareTunnelToken": "..."
  "namedTunnelUrl": "https://gw.example.com"
Env: CLOUDFLARE_TUNNEL_TOKEN
Token bo‘lmasa → trycloudflare (URL har safar o‘zgarishi mumkin)

O‘chirish
---------
uninstall-service.bat (ADMIN)

Eslatma
-------
• Faqat .exe ni nusxalamang — butun ilova / release papkasi kerak
• Firewall: lokal 8800 va cloudflared ga ruxsat
• link.key / token ni operatorga ko‘rsatmang
