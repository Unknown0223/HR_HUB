# Form / FormModal qoida (F6)

1. **List create** — markaziy `FormModal` (`?create=1` deep-link).
2. **`/new` route** — faqat `redirect(...?create=1)`, to‘liq forma sahifa emas.
3. **`XForm.tsx` + `XFormModal.tsx`** — modal yupqa wrapper; business forma bitta `XForm` da (`embedded` / `mode`).
4. Yangi dublikat juft yaratmang: avval mavjud Form ni modalga o‘rang.
